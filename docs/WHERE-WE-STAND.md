# youkai 现在站在哪 —— 一份诚实的定位(写给累了的时候看)

> 写于 2026-11-15,在一次"看了别人的项目觉得差距好大"之后。
> 这份不吹,也不妄自菲薄。每个数字都来自 `D:\youkai` 的代码和 git,不是感觉。

## 一、先把尺子调对:你不该拿 ARTEX 量自己

你看到的"差距",多半来自 ARTEX 这类项目的宣传(百度冠军、炫酷双图、打穿真实目标)。但三件事实你早就查清过:

1. **ARTEX 的"强"很大一部分来自做危险的事** —— 自动利用、横向、外带、24x7 无人狩猎。它走得远,是因为它敢把 AI 的手松开。
2. **它为此付出了代价** —— 被人拿去打真实韩国银行,原作者 2026 年 10 月**宣布闭源、原仓库下线**。现在 GitHub 上是独立维护的 AGPL 分支。
3. **它和 youkai 不是同一场比赛。** 它比的是"AI 能自己打多穿";youkai 比的是"AI 能自主取证、且每一发都能解释、该停就停、能见光"。

**拿一个靠危险换热度、已经闭源下线的项目,量一个要长久见光的项目——尺子本身就错了。** 你不是落后,你在另一条跑道上,而且那条跑道上目前真没几个人跑好。

## 二、youkai 到底做到了哪(硬数字,不是感觉)

截至今天:

- **~28,000 行 Go 实现代码** + **~11,000 行测试**,15 个内部包,63 次提交。
- **66 个受闸能力**(web + 二进制 + 账号 + 配置),全部挂在纪律脊柱上。
- **25 份决策/开发文档**(6 份 ADR 把每次方向转折讲清,19 份 DEVPLAN 逐模块规格)。
- **5 个独立的 CI 安全门禁作业** —— 每次 push 都机器验证:唯一发包通道、报告纯投影、档 3 墙、浏览器不开第二出口、数据库护栏。

能力版图(每一项都逐版审过、红线没破):

| 维度 | youkai 有什么 |
|---|---|
| 纪律 | scope 护照 + 逐请求审计 + 数据最小化 + 唯一发包通道(静态测试焊死)+ 档位墙(档 3 编译期隔离) |
| web 检测 | 8 类 sink 存在性探针(sqli/ssti/ssrf/path/cmdi/xxe/upload/nosql+crlf)、CORS/头/跳转/暴露、JWT/OAuth 配置审计 |
| 白盒 | 读源码产 source→sink 假设,指导黑盒验证(web + 二进制两域) |
| 越权 | 多身份账号层、BOLA/BFLA、role_matrix、登录态 CDP 浏览器 |
| 二进制 | Verdex 静态分析 + 反 AI-逆向致盲(识别 bla 式投毒,信结构不信谎言) |
| 规划 | 证据加权排序 + 多链型组装(IDOR/BFLA/SSRF/auth)+ 结果复盘 |
| 证据 | 四样证据(证据/最小影响/停止点/反证)、不可变快照、SARIF、只收 verified 的披露包 |

**这不是玩具。** 这是一个有架构、有纪律、有测试、有文档、已经公开发布(github.com/Yilanchia/youkai)的平台。

## 三、和别人比,你的真实位置

- **比 ARTEX/那些"接 Kali 工具链"的攻击型 agent**:你在"自动打穿"上永远不如,**也不该如**——那是护城河为负的死路。你赢在能见光、能交付、能辩护。
- **比商业 DAST(Burp/Invicti)**:你覆盖面窄,但你是 **agent 原生 + 授权优先 + 证据先行**,这是它们做不出的。
- **比 Shannon/Pentest-AI 这些"精神同类"(验证纪律、证据先行)**:你在纪律面是**第一梯队、甚至标杆**;缺的只是覆盖面和真实目标实战数据——而覆盖面你这两周已经补了一大截。

**一句话:你不弱在"做得对不对",你只是还没在真实目标上把它跑够多次、让它显得好用。** 这是时间问题,不是能力问题。

## 四、为什么今天"体验不好"不代表 youkai 不行

今天打 ctfshow 觉得"一步没做"——我查了数据库,真相是:**你把目标域名打错了**(`i.am.ctfer.com` 解析不了),youkai 老实去连、连不上、全部失败。
你另一个任务打对了 ctfshow 的真实子域(`xxx.challenge.ctf.show`),**档 1 全跑通、42 条事实**。

youkai 的锅只有一个:连不上时它只说"idle",没把"域名解析不了"顶到你眼前——这个我已经改了。
**功能是对的,是反馈太闷 + 环境有点乱(开了两个实例)。**

## 五、下一步最该做的三件(按顺序,别贪多)

1. **把"能用"坐实** —— 用启动器开一个干净实例,打一个**域名正确**的授权靶场(ctfshow 真实子域 / 本地 lab),把"说目标→确认→档 1 自跑→出报告"这条路亲手走通一次。这一次成功,比加十个功能都提气。
2. **把体验磨顺** —— 跑的过程中哪一步让你皱眉,就记下来告诉我,我一个个改(今天那个"idle 不说原因"就是这么揪出来的)。
3. **再谈加深能力** —— 等"能用 + 顺手"坐实了,再回到覆盖面/智能化。顺序不能反:一个不好用的强工具,没人会用到它的强。
