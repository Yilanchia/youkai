## 一句话

同一个 youkai,现在**先问"测哪个网址"**,其余按安全默认填好;专家旋钮收进「高级选项」,
每个旁边写着它解锁什么。安全默认一分没松。

## 一 · 新建任务:只问一个问题

- 默认可见:**网址** + **一句授权确认**(勾了才能建)。
- 自动派生(用户看不到也能跑):`include` = 该网址,`methods` = GET/HEAD/OPTIONS,
  所有高风险开关关闭,`max_requests` 默认,**到期 +7 天**,
  `basis` = `向导确认:操作员声明有权测试 <host> @ <时间>`(满足 ≥8 字与授权语义)。
- **本机/内网地址自动允许**,并在输入框下面明说一行:"识别为本机/内网地址,已自动允许" ——
  这是实际操作里最容易踩的坑(不勾就每个请求都被拦,而那个开关藏在高级里)。
- 「高级选项」折叠:exclude、方法集、五个高风险开关、请求上限、限速、到期、授权依据、操作员。
  每个高风险开关**一句人话 + 它解锁什么**,并重申"仍然每次都要你批准"。

## 二 · 首启引导 + 常驻"下一步"

- 顶部三步:**① 配 AI(可选)→ ② 新建任务 → ③ 开始扫描**;完成打勾、当前步高亮。
  AI 那步在"建成任务"后即视为跨过 —— 可选的东西不许一直唠叨。
- 常驻一行「下一步」,从状态派生:没任务→建任务;有任务没跑→开始扫描;停了高风险→去待办审批;
  跑完了→去结果。右侧永远有一个对应的按钮。
- 第 1 步内嵌**精简 AI 卡**:provider 预设(DeepSeek / OpenAI 兼容 / 自定义自动填 base_url)、
  model、key 一个框、"保存并测试连接"(先 PUT 再 POST test,key 只显示"已配置")。
  卡里明确写着:**不配也能用**。

## 三 · 侧边栏与文案

- 导航:**开始 / 待办审批 / 结果 / 账号 / 设置**,探索图与审计日志折进「更多」。
- 全站去黑话:护照→授权范围、档 2→高风险(需你确认)、作业→任务、隔离墙→安全边界、
  证据·报告→结果、tier 1→"只读检查"。
- 运行记录的停止原因翻成人话(`no claimable intent…` → "这一轮没有可做的新步骤了")。
- 「开始」面板加一行结果摘要(请求数/发现数)+「看结果」直达。

## 四 · 顺手修的两个真问题(都是实际操作暴露的)

1. **令牌失效时的提示没法看**:页面上写着 `保存失败:missing or invalid token`,用户以为是表单问题。
   现在 401 直接把人送回令牌输入页,并说清"从启动窗口复制完整地址"。
2. **失败步骤永久卡死**:一次临时失败(靶场没开)会把该能力标 `blocked`,不 claim 也不重派生,
   只能等人工救。新增 `POST …/intents/{id}/retry`:只读步骤回队列,高风险步骤回到待审批
   (旧的批准已消费,要重新批)。「开始」面板出现「重试 N 个失败步骤」。

## 验收(真机点过)

- 只填 `http://127.0.0.1:18080` + 勾授权 → 建成任务 → 自动勾上"本机地址" →
  点「开始扫描」→ 10 次请求、7 条发现、0 越界 → 顶栏变成"去结果"。
- 高级面板:11 个字段全在,每个开关有解释;不展开也能跑完。
- AI 卡:填 base_url + model + key → 保存 → 测试连接 → key 框清空、界面只显示"已配置"。
- `go test ./...` 全绿;新增 `TestRetryRequeuesABlockedStep` 钉住重试语义
  (只对 blocked 生效,非 blocked 返回 400)。

## 与 DEVPLAN-v0.10 的差异 / 未做

- **没有做"provider 预设自动填 model"之外的推理**:base_url 与 model 仍是预设表里写死的两套,
  自定义需要手填。
- **AI 卡放在"无任务"时的引导区**,不做成常驻首屏;有任务后从「设置」进。
- **引导三步不做持久化**:每次刷新按当前状态重新判断是否显示,已完成的步骤仍显示打勾(不写 localStorage)。
- **没有截图进 README**:文字流先到位,截图随后补。
