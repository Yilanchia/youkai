# DEVPLAN-v0.10:极简向导式 UX 重做(让非专家也能跑起来)

> 交付对象:实现者(DeepSeek)。配 ADR-003(平台/面板)、DEVPLAN-v0.4(配置 API)、v0.9 读。
> 背景:真实用户(维护者本人)反馈 —— **配置太多看不懂、找不到填 AI key 的入口、新建作业的字段看不懂、不知道从哪开始**。
> 功能是全的,但可用性差到等于功能不存在。本轮**不加检测能力、不动任何安全不变量**,只重做前端交互:默认极简,专家旋钮收起。

## 0. 诊断(四块卡点,均为 UI 问题)

1. **新建作业表单**:一上来要填 授权依据/high-auth 路径/方法/一堆 allow 开关,普通用户不知道填什么。
2. **AI key 入口找不到**:其实在"配置 · 隔离墙"面板里(`renderConfig`,v0.4 已实现),但埋太深、名字也不像"配 AI"。
3. **导航/术语混乱**:侧边 7 面板(审批台/证据/任务/图/账号/配置/审计)+ "护照/档位/high-auth/materialise" 等黑话,没有引导。
4. **不知道从哪开始**:打开页面后没有"第一步做什么"的指引。

## 0.5 不可动摇(继承,逐条适用)

- **只改前端表现(`web/app.js`/`index.html`/`style.css`)+ 必要的 API 便利端点**;不动 `discipline`/`gate`/`engine`/`ledger` 的任何安全逻辑。
- **极简 ≠ 放松**:默认值只能是**更安全**的那一侧 —— 只读方法、active/waf 开关默认关、scope 仍必填、档 2 仍人批、high-auth 仍必需。向导只是**替用户把安全默认填好**,不是跳过它们。
- AI key 仍走 v0.4 的加密存储 / env 引用,**绝不回显**;向导里填 key 走同一条 `PUT /api/config/llm`。
- 不新增"一键自动利用"类入口;审批台仍一次一个、无"全部放行"。

## 1. 首次启动引导 + "下一步"常驻条(P0)

**目标**:打开控制台后,一眼知道"现在该做什么"。

- **首次(无 LLM key / 无作业时)**:顶部显示一个 3 步进度条:**① 配 AI(可选)→ ② 新建作业 → ③ 开始扫描**。每步完成打勾,当前步高亮并带一句话说明。
- **常驻"下一步"横幅**:顶栏始终有一句话告诉用户此刻该干嘛,从状态派生:
  - 无 key → "想让 AI 帮你规划?去配置填一个 API key(不填也能用,走内置规则)。"
  - 无作业 → "新建一个作业:告诉 youkai 测哪个网址。"
  - 有作业无运行 → "点『开始扫描』,youkai 会自己跑只读检查。"
  - 停在档 2 → "有 N 个动作在等你批准(审批台)。"
- 术语去黑话:UI 文案层面 **"作业"→"任务/扫描"**、**"护照/scope"→"授权范围"**、**"档 2"→"需要你确认的高风险动作"**、**"materialise/tick"** 等内部词不出现在 UI。

**验收**:全新环境打开 → 看到 3 步引导;每完成一步进度更新;顶栏"下一步"随状态变化;UI 无 materialise/tick/护照 等黑话。

## 2. 新建作业:极简向导(P0,最卡的一块)

**目标**:新建作业默认**只问一个问题**:测哪个网址。其余全部给安全默认值,收进"高级"。

**极简层(默认可见)**:
- 一个输入框:**"要测试的网址"**(如 `http://127.0.0.1:8080` 或 `https://lab.example.com`)。
- 一句授权确认勾选:**"我确认有权测试这个目标(自建靶场 / 我拥有 / 已获授权)"** —— 勾了才能建。
- 建立按钮。

**自动填的安全默认(用户看不到也能跑)**:
- `include` = 输入的 host;`basis` = 勾选时自动记 "operator-confirmed via wizard @ <时间>"(满足 ≥8 字与授权依据语义);
- `methods` = 只读(GET/HEAD/OPTIONS);所有 allow 开关 = 关;`expires_at` = +7 天;`max_requests` = 安全默认。

**高级层(默认折叠,点"高级选项"才展开)**:exclude、方法集、active_probes/waf_probe/object_seeding/account_provisioning 开关、max_requests、rate、过期时间、basis 手填、approver。每个旁边一句**人话解释 + 它解锁什么**(如"打开『主动探针』= 允许做 SQL/SSTI 存在性测试,属于需你逐步批准的高风险动作")。

**验收**:只填网址 + 勾授权 → 作业建成并能开始只读扫描;不展开高级也完全可用;高级里每个开关有人话解释;后端收到的 scope 仍是合法护照(走现有校验)。

## 3. AI key:挪到显眼处 + 讲清"可选"(P0)

**目标**:让"配 AI"成为首屏引导的第一步,且说清不配也能用。

- 首屏 3 步引导的第①步直接内嵌一个**精简 LLM 配置卡**:provider 预设下拉(DeepSeek / OpenAI 兼容 / 自定义,预填对应 base_url)、model、API key 一个框。填完"保存并测试连接",显示 ✓/✗。
- 明确标注:**"不配 AI 也能用 —— youkai 有内置确定性规则会自己跑;配了 AI 它能规划得更聪明。"**
- 配置面板(原 renderConfig)保留完整版,但改名更直白:**"配置"**,LLM 段放最上面、隔离墙段放下面(只读状态)。
- key 走现有 `PUT /api/config/llm`,env/直填两模式保留但默认直填(向导场景更直觉),仍加密存储、不回显。

**验收**:首屏就能填 AI key 并测连通;provider 选 DeepSeek 自动填 base_url;不填 key 能继续建作业跑扫描;key 不回显。

## 4. 侧边栏瘦身 + 面板讲人话(P1)

**目标**:7 面板按"用户旅程"重排 + 改名,新手默认只看到前几个。

- 重排与改名(UI 文案):**开始(原任务台+新建)/ 待办审批(原审批台)/ 结果(原证据·报告)/ 账号(登录身份)/ 设置(原配置)**;探索图、审计日志折到"更多"里(高级/排错用)。
- 每个面板顶部一句话说明它是干嘛的。
- 空态文案全部改成"下一步指引"式(已有雏形,统一润色)。

**验收**:侧边栏默认 ≤5 项,高级项在"更多"里;每面板有一句自解释;术语讲人话。

## 落地顺序

1. 模块二(新建作业极简向导)+ 模块三(AI key 挪到首屏)—— 两个最卡点,先做。
2. 模块一(首启引导 + 下一步常驻条)。
3. 模块四(侧边栏瘦身 + 讲人话)。
4. 模块五(README 上手流)。

**每步验收锚点**:新手只填"网址+授权确认"就能跑完一次只读扫描;AI key 首屏可配且标注可选;UI 无内部黑话;后端 scope 仍是合法护照、默认全是更安全的一侧;所有安全不变量测试仍绿(`go test ./...` 不受影响,纯前端改动)。

## 一句话

youkai 的安全是对的,但它现在只对看得懂它的人友好。v0.10 把"替用户把安全默认填好"做成默认路径 ——
普通人只回答"测哪个网址",专家才展开那一堆旋钮;安全一分没松,门槛降到地面。
